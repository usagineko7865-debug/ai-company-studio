# AI Company Studio

这是一款本地网页应用。你可以与由 ChatGPT 担任的 CEO、由 Claude 担任的 CTO 共同发展业务，并把成功方法制作成可复制、可销售给他人的“公司模板”。Phase 1为此建立业务创建和记录基础。

- 可切换免费模拟模式和真实 AI
- 将对话保存为商业方案
- 将证据、可复现步骤和失败条件保存为可移植的公司模板
- 每次 API 请求前检查预算
- 支持日语、英语、简体中文、巴西葡萄牙语和西班牙语

在 Windows 中从 Releases 下载 Windows ZIP，然后双击 `AI-Company-Studio.exe`；无需安装 Python。Phase 1 用于验证需求，不会自动公开、销售或购买任何内容。付费版计划使用 Stripe 管理订阅和收入。
