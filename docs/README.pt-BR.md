# AI Company Studio

Um aplicativo web local no qual você, um CEO baseado no ChatGPT e um CTO baseado no Claude criam um negócio. O diferencial é transformar um método comprovado em um “modelo de empresa” reproduzível que o criador possa vender a outras pessoas. A Fase 1 cria a base de desenvolvimento e registro.

- Alternância entre modo simulado gratuito e IA real
- Conversas salvas como ideias de negócio
- Provas, etapas reproduzíveis e condições de falha salvas como modelo de empresa portátil
- Controle de orçamento antes de cada chamada de API
- Disponível em japonês, inglês, chinês simplificado, português do Brasil e espanhol

No Windows, baixe o ZIP para Windows em Releases e clique duas vezes em `AI-Company-Studio.exe`; não é necessário instalar Python. A Fase 1 serve para validar a demanda e não publica, vende nem compra nada automaticamente. As assinaturas e receitas da edição paga serão gerenciadas pelo Stripe.
