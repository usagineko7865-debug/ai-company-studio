# 会社テンプレート

会社テンプレートは、うまくいった事業を「他の人が試せる運営方法」に変えるための非公開ドラフトです。

## 現在記録できる内容

- テンプレート名
- 誰の、どんな問題を解決する会社か
- 実際に得られた結果
- 結果を確認できる証拠
- 他の人が再現する手順
- うまくいかない条件・注意点

画面で「下書きを保存」を押すと、このPC内だけに保存されます。「JSONで書き出す」を押した時だけ、持ち運び可能なファイルになります。別の環境で読み込むときは、現在のデータを自動的にバックアップしてから置き換えます。

## 安全性

書き出しファイルには、APIキー、会話ログ、端末内の利用回数を含めません。ただし、証拠欄などへ氏名・メールアドレス・顧客情報・秘密情報を書かないでください。公開や販売の前には、内容を人間が確認してください。

## 成功の保証ではありません

テンプレートは「この条件ではこう進めた」という検証記録です。同じ結果を保証するものではありません。再現性を高めるため、良い結果だけでなく、必要な前提、かかった費用、失敗条件、改善履歴も記録する設計へ発展させます。

## 将来の販売市場との関係

Phase 5では、テンプレートへ実績の確認、版管理、利用条件、価格、購入者向け更新、作成者への還元を加え、Stripeを使った販売につなげる計画です。現在のPhase 1では、出品・購入・決済は行いません。
