# AI Company Studio

Una aplicación web local donde tú, un CEO basado en ChatGPT y un CTO basado en Claude crean un negocio. Su diferencia central es convertir un método probado en una “plantilla de empresa” reproducible que su creador pueda vender a otras personas. La Fase 1 establece la base de creación y registro.

- Cambio entre simulación gratuita e IA real
- Conversaciones guardadas como ideas de negocio
- Pruebas, pasos reproducibles y condiciones de fallo guardados como plantilla de empresa portátil
- Control del presupuesto antes de cada llamada a la API
- Disponible en japonés, inglés, chino simplificado, portugués de Brasil y español

En Windows, descarga el ZIP para Windows desde Releases y haz doble clic en `AI-Company-Studio.exe`; no necesitas instalar Python. La Fase 1 sirve para validar la demanda y no publica, vende ni compra nada automáticamente. Las suscripciones y los ingresos de la edición de pago se gestionarán con Stripe.
